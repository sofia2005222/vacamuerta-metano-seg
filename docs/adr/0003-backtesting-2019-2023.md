# Backtesting sobre 2019–2023 en lugar de detección en tiempo real

La utilidad del sistema se mide con un backtesting: el modelo se corre sobre imágenes históricas de 2019–2023 y la primera detección de cada locación nueva se compara con el inicio de perforación de su primer pozo, que da el padrón de pozos. No se hace detección en tiempo real porque no habría contra qué validarla. Con las fechas oficiales se puede medir qué porcentaje de las locaciones nuevas se detectan y con cuánta anticipación (mediana, en meses).

## Consecuencias

- Si falta tiempo, el backtesting es lo primero que se recorta. La evaluación del modelo no se recorta nunca.
